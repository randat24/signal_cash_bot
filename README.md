# Signal Cash

Веб-приложение — журнал торговых сигналов. Вместо Telegram-бота: страница с формой,
таблицей сигналов, автоматическими расчётами и синхронизацией с Google Таблицей.

## Возможности

- **Форма сигнала**: тикер/пара, рынок, LONG/SHORT, вход, стоп-лосс, тейк-профит, объём
  позиции в $, статус, цена выхода, источник (канал/автор), заметка.
- **Проверка уровней**: для LONG стоп ниже входа и тейк выше, для SHORT — наоборот.
- **Расчёты на лету**: R:R, риск в % и $, потенциальная прибыль, итог сделки в %, $ и R.
- **Статистика**: win rate, общий P&L, средний результат, средний R, profit factor.
- **Таблица**: поиск, фильтры по статусу и направлению, сортировка по колонкам,
  редактирование, дублирование, удаление. На телефоне строки превращаются в карточки.
- **Google Таблица**: загрузка сигналов из таблицы и отправка в неё, опционально — автоотправка
  после каждого изменения.
- **CSV**: экспорт и импорт (разделитель `,` или `;`, открывается в Excel).
- Светлая и тёмная темы. Данные хранятся в браузере (localStorage).

## Запуск

Сборка не нужна — это статические файлы.

```bash
npm start        # http://localhost:3000
npm test         # тесты расчётов и CSV
```

Можно выложить как есть на GitHub Pages, Vercel или Netlify (корень репозитория).

## Подключение Google Таблицы

1. Создайте Google Таблицу.
2. «Расширения → Apps Script», замените содержимое файла кодом из
   [`google-apps-script/Code.gs`](google-apps-script/Code.gs). При желании задайте `TOKEN`.
3. «Развернуть → Новое развёртывание → Веб-приложение»:
   запуск — «от моего имени», доступ — «Все». Скопируйте URL вида
   `https://script.google.com/macros/s/…/exec`.
4. В приложении нажмите «Google Таблица», вставьте URL (и токен, если задали) и сохраните.

Скрипт хранит сигналы на листе `Signals`, по одной строке на сигнал.
«Отправить в таблицу» перезаписывает лист текущим списком; «Загрузить из таблицы»
добавляет и обновляет сигналы по `id`. Строки, добавленные в таблицу вручную без `id`,
получат его при загрузке.

## Структура

```
index.html                 разметка страницы
src/core.js                расчёты, статистика, CSV (без DOM, покрыто тестами)
src/sheets.js              обмен с Google Apps Script
src/app.js                 интерфейс
src/styles.css             стили, темы, мобильная вёрстка
google-apps-script/Code.gs серверная часть для Google Таблицы
test/core.test.js          тесты
```
